## I. TỔNG QUAN KIẾN TRÚC & LỢI ÍCH CỦA DIRECTORY JUNCTION

Thông thường khi lập trình WordPress trên XAMPP, lập trình viên hay copy toàn bộ source code vào `D:\xampp\htdocs\`. Tuy nhiên cách làm này có nhiều nhược điểm:
1. Dễ mất code khi cài lại hoặc nâng cấp XAMPP.
2. Khó phân chia cây thư mục dự án theo năm, khách hàng hoặc ổ đĩa riêng.
3. Không đồng bộ trực tiếp với Git repository nằm ở thư mục làm việc bên ngoài.

**Giải pháp**: Sử dụng **Windows Directory Junction** (`mklink /J`).
- Thư mục mã nguồn chính vẫn nằm an toàn tại ổ `E:`.
- Tạo một liên kết trỏ từ `D:\xampp\htdocs\gobike` sang ổ `E:`.
- Apache trên XAMPP đọc và thực thi trực tiếp như thể thư mục nằm bên trong `htdocs`.
- Mọi chỉnh sửa code tại ổ `E:` ngay lập tức có hiệu lực trên trình duyệt mà không cần copy hay build.


## II. CÁC BƯỚC THỰC HIỆN TỪNG BƯỚC (STEP-BY-STEP)

### Bước 1: Tạo liên kết Directory Junction trong Command Prompt (CMD)

Mở **Command Prompt (CMD)** hoặc PowerShell với quyền Administrator và chạy lệnh:

```cmd
mklink /J "D:\xampp\htdocs\gobike" "E:\1. DỰ ÁN THỰC TẾ (2026)\(17) GOBIKE (28082026)"
```

**Kết quả thành công**:
```text
Junction created for D:\xampp\htdocs\gobike <<===>> E:\1. DỰ ÁN THỰC TẾ (2026)\(17) GOBIKE (28082026)
```

**Cách kiểm tra**:
Chạy lệnh kiểm tra trong `htdocs`:
```cmd
dir D:\xampp\htdocs | findstr gobike
```
Sẽ thấy dòng hiển thị:
```text
<JUNCTION>     gobike [E:\1. DỰ ÁN THỰC TẾ (2026)\(17) GOBIKE (28082026)]
```

### Bước 2: Cấu hình Cơ sở dữ liệu MySQL

Cơ sở dữ liệu của dự án là **`thangma1_gobike`** đã có sẵn trên XAMPP MySQL (`D:\xampp\mysql\data\thangma1_gobike`).

#### 1. Tạo User và cấp quyền truy cập MySQL
Mở CMD hoặc terminal chạy các lệnh sau vào MySQL:
```cmd
D:\xampp\mysql\bin\mysql.exe -u root -e "CREATE USER IF NOT EXISTS 'thangma1_gobike'@'localhost' IDENTIFIED BY ''; GRANT ALL PRIVILEGES ON thangma1_gobike.* TO 'thangma1_gobike'@'localhost'; FLUSH PRIVILEGES;"
```

#### 2. Cập nhật URL trong Database (bảng `wp_options`)
Mặc định database trỏ về tên miền live (`https://gobike.demoweb360.top`). Cần cập nhật `siteurl` và `home` sang `http://localhost/gobike`:
```cmd
D:\xampp\mysql\bin\mysql.exe -u thangma1_gobike thangma1_gobike -e "UPDATE wp_options SET option_value = 'http://localhost/gobike' WHERE option_name IN ('siteurl', 'home');"
```

### Bước 3: Cấu hình tệp `wp-config.php`

Mở tệp [wp-config.php](file:///e:/1.%20D%E1%BB%B0%20%C3%81N%20TH%E1%BB%B0C%20T%E1%BA%BE%20(2026)/(17)%20GOBIKE%20(28082026)/wp-config.php) và kiểm tra các thiết lập sau:

#### 1. Thông số kết nối Database
```php
define( 'DB_NAME', 'thangma1_gobike' );
define( 'DB_USER', 'thangma1_gobike' ); // hoặc 'root'
define( 'DB_PASSWORD', '' );
define( 'DB_HOST', 'localhost' );
define( 'DB_CHARSET', 'utf8mb4' );
```

#### 2. Cố định URL chạy Localhost (Tự động nhận diện, an toàn khi đưa lên hosting)
Thêm đoạn sau trước dòng `/* That's all, stop editing! Happy publishing. */`:
```php
/* Cấu hình URL tự động cho Localhost (Không ảnh hưởng khi đưa lên hosting/server) */
if ( isset( $_SERVER['HTTP_HOST'] ) && ( $_SERVER['HTTP_HOST'] === 'localhost' || $_SERVER['HTTP_HOST'] === '127.0.0.1' ) ) {
	if ( ! defined( 'WP_SITEURL' ) ) {
		define( 'WP_SITEURL', 'http://localhost/gobike' );
	}
	if ( ! defined( 'WP_HOME' ) ) {
		define( 'WP_HOME', 'http://localhost/gobike' );
	}
}
```
*(Đoạn code này chỉ kích hoạt khi chạy trên `localhost` hoặc `127.0.0.1`, khi đưa lên server/hosting thật sẽ tự bỏ qua, không làm hỏng domain chính).*

### Bước 4: Tạo tệp điều hướng [.htaccess](file:///e:/1.%20D%E1%BB%B0%20%C3%81N%20TH%E1%BB%B0C%20T%E1%BA%BE%20(2026)/(17)%20GOBIKE%20(28082026)/.htaccess)

Do WordPress chạy trong thư mục con `/gobike/` trên localhost, bắt buộc phải có `.htaccess` với `RewriteBase /gobike/` để các trang con, danh mục và sản phẩm không bị lỗi **404 Not Found**:

```apache
# BEGIN WordPress
<IfModule mod_rewrite.c>
RewriteEngine On
RewriteBase /gobike/
RewriteRule ^index\.php$ - [L]
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule . /gobike/index.php [L]
</IfModule>
# END WordPress
```

## IV. XỬ LÝ SỰ CỐ THƯỜNG GẶP (TROUBLESHOOTING)

### 1. Bị tự động chuyển hướng (Redirect) về web live `gobike.demoweb360.top`
- **Nguyên nhân**: Giá trị `siteurl` và `home` trong bảng `wp_options` của database vẫn lưu domain live.
- **Cách khắc phục**:
  1. Kiểm tra lại Bước 2 (chạy query cập nhật `wp_options`).
  2. Kiểm tra `wp-config.php` đã có `define( 'WP_HOME', 'http://localhost/gobike' );` và `define( 'WP_SITEURL', 'http://localhost/gobike' );`.
  3. Xóa cache trình duyệt hoặc mở tab ẩn danh (Incognito / InPrivate).

### 2. Vào trang sản phẩm hoặc trang con bị lỗi `404 Not Found`
- **Nguyên nhân**: Thiếu file `.htaccess` hoặc Apache chưa bật `mod_rewrite`.
- **Cách khắc phục**:
  1. Đảm bảo file `.htaccess` tồn tại tại thư mục gốc dự án với nội dung ở Bước 4.
  2. Vào `WP Admin` ➔ `Cài đặt (Settings)` ➔ `Đường dẫn tĩnh (Permalinks)` ➔ Bấm **Lưu thay đổi (Save Changes)** để WordPress tự flush rewrite rules.

### 3. Cách hủy bỏ liên kết (Xóa Junction) an toàn
> [!CAUTION]
> **CẢNH BÁO QUAN TRỌNG**: Khi muốn xóa liên kết trong `htdocs`, **TUYỆT ĐỐI KHÔNG** dùng chuột chọn `Delete` trong File Explorer hoặc chạy lệnh `del /s /q` vì Windows có thể xóa sạch file trong thư mục gốc ở ổ `E:`.

Để xóa liên kết một cách an toàn mà **không làm mất** bất kỳ file nào ở ổ `E:`:
```cmd
rmdir "D:\xampp\htdocs\gobike"
```
*(Lệnh `rmdir` trên thư mục Junction chỉ gỡ bỏ liên kết tượng trưng, toàn bộ dữ liệu ở ổ `E:` được bảo toàn 100%).*
