## II. BỐ CỤC VỊ TRÍ CHUẨN 3 TẦNG (FIX LỖI BỊ NGƯỢC THỨ TỰ)

### 1. Nguyên nhân bị ngược trước đây
- Trước đây, hook `woocommerce_before_shop_loop` gọi HUSKY top panel (`[woof_search_options]`) và thanh sắp xếp trước, sau đó mới gọi shortcode `[woof]` (Tìm theo:).
- Hậu quả: Dải **Bỏ hết** bị đẩy lên trên cùng, kế tiếp là **Xếp theo:**, và **Tìm theo:** lại nằm ở dưới cùng (bị đảo ngược 180° so với mẫu GOBIKE).

### 2. Cấu trúc chuẩn sau khi tái cấu trúc
```
┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ TẦNG 1: Tìm theo:  [Thương hiệu ▼]  [Giá sản phẩm ▼]  [Loại ▼]  [Kích thước ▼]  [Reset]               │
├────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ TẦNG 2: [GT20 ✕]  [M26 Pro ✕]  [Giá dưới 5.000.000đ ✕]  ...  [Bỏ hết ✕ (Nút đỏ)]                       │
├────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ TẦNG 3: Xếp theo:  ( ) Tên A-Z   ( ) Tên Z-A   (●) Hàng mới   ( ) Giá thấp đến cao   ( ) Giá cao xuống │
└────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                                    ▼
                             LƯỚI SẢN PHẨM WOOCOMMERCE (5 CỘT)
```

### 3. Giải pháp kỹ thuật 2 lớp (PHP Template + JS DOM Reorder)
1. **Lớp PHP trong [category-none.php](file:///e:/1.%20D%E1%BB%B0%20%C3%81N%20TH%E1%BB%B0C%20T%E1%BA%BE%20%282026%29/wp-content/themes/flatsome-child/woocommerce/layouts/category-none.php)**:
   Xếp chuẩn theo trình tự:
   ```php
   // 1. Dòng 1: Tìm theo:
   if ( shortcode_exists( 'woof' ) && ! did_action( 'woof_before_filter' ) ) {
       echo do_shortcode( '[woof autohide="0" autosubmit="1" is_ajax="1"]' );
   }
   // 2. Dòng 2: Badges đang chọn & Nút Bỏ hết
   if ( shortcode_exists( 'woof_search_options' ) ) {
       echo do_shortcode( '[woof_search_options]' );
   }
   // 3. Dòng 3: Xếp theo:
   if ( function_exists( 'gobike_render_custom_sorting_toolbar' ) ) {
       gobike_render_custom_sorting_toolbar();
   }
   // 4. Hook mặc định của WooCommerce
   do_action( 'woocommerce_before_shop_loop' );
   ```

2. **Lớp JavaScript trong [gobike-product-filter.php](file:///e:/1.%20D%E1%BB%B0%20%C3%81N%20TH%E1%BB%B0C%20T%E1%BA%BE%20%282026%29/wp-content/themes/flatsome-child/gobike-product-filter.php)**:
   Hàm `reorderGobikeFilterElements()` tự động cưỡng chế thứ tự các phần tử DOM ngay khi tải trang và sau mỗi sự kiện AJAX của HUSKY (`woof_ajax_done`):
   ```javascript
   function reorderGobikeFilterElements() {
       var $redrawZone = $('.woof_redraw_zone').first();
       var $topPanel = $('.woof_products_top_panel').first();
       var $sortingToolbar = $('.gobike-custom-sorting-toolbar').first();

       if ($redrawZone.length) {
           if ($topPanel.length) {
               $topPanel.insertAfter($redrawZone);
           }
           if ($sortingToolbar.length) {
               if ($topPanel.length && $topPanel.is(':visible') && $topPanel.find('li').length > 0) {
                   $sortingToolbar.insertAfter($topPanel);
               } else {
                   $sortingToolbar.insertAfter($redrawZone);
               }
           }
       }
   }
   ```

## III. CHI TIẾT TỪNG THÀNH PHẦN KỸ THUẬT ĐÃ XỬ LÝ

### 1. Nút "Bỏ hết ✕" & Dải Huy hiệu (Active Badges)
- **Nút Bỏ hết đỏ chuẩn mẫu**:
  - Selector: `.woof_products_top_panel .woof_reset_button_2`
  - Nền đỏ đậm `#d0021b`, chữ trắng in đậm, bo góc 5px, tự động thêm biểu tượng `✕`.
  - Hover chuyển sang đỏ sẫm `#b50217`, đổ bóng nhẹ `box-shadow`.
- **Dải Badges 6 màu luân phiên**:
  - Ẩn toàn bộ các nhãn phân loại thô lồng nhau (`Thương hiệu:`, `Danh mục sản phẩm:`).
  - Từng badge mang màu sắc rực rỡ luân phiên: Cyan (`#00b4d8`), Đỏ san hô (`#e63946`), Xanh ngọc (`#2a9d8f`), Cam (`#f77f00`), Tím hồng (`#7209b7`), Xanh dương (`#3a86ff`).
  - Đuôi mỗi badge có icon `✕` để xóa từng tiêu chí riêng lẻ.

### 2. Bộ lọc "Khoảng giá" (Price Range)
- **Việt hóa 100%**: Thay thế triệt để chữ tiếng Anh "Price range" ở cả 2 cấp độ PHP filter (`gettext`) và JavaScript DOM replace.
- **5 Mốc giá tiêu chuẩn**: Dưới 5 triệu, 10 - 15 triệu, 15 - 20 triệu, 20 - 30 triệu, Trên 30 triệu kèm định dạng tiền tệ VNĐ có dấu chấm phân cách hàng nghìn.

### 3. Thanh sắp xếp Radio (Custom Sorting Toolbar)
- **5 Tiêu chí**: Tên A-Z (`title-asc`), Tên Z-A (`title-desc`), Hàng mới (`date`), Giá thấp đến cao (`price`), Giá cao xuống thấp (`price-desc`).
- **Thiết kế nút Radio**: Nút tròn đường kính 16px viền xám nhạt, khi chọn hiển thị viền đỏ và chấm tròn đỏ 8px ở tâm chuẩn nhận diện thương hiệu GOBIKE.
- **Đồng bộ tham số URL**: Kết nối tự động với `?orderby=...` của WooCommerce và hỗ trợ HUSKY AJAX.

## V. HƯỚNG DẪN GỌI HÀM & TÍCH HỢP

### 1. Hệ thống Shortcodes
- `[gobike_full_filter]`: Hiển thị trọn gói 3 tầng (Tìm theo: ➔ Badges ➔ Xếp theo:) thích hợp dùng cho mọi trang.
- `[gobike_sorting_toolbar]`: Hiển thị riêng thanh radio sắp xếp "Xếp theo:".
- `[gobike_filter]`: Hiển thị riêng khối dropdown bộ lọc ngang.

### 2. Tích hợp trong PHP Template
```php
// Render thanh sắp xếp radio trực tiếp
if ( function_exists( 'gobike_render_custom_sorting_toolbar' ) ) {
    gobike_render_custom_sorting_toolbar();
}

// Hoặc render toàn bộ qua shortcode
echo do_shortcode( '[gobike_full_filter]' );
```
