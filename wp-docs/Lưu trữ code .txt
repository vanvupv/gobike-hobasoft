II. BẢN ĐỒ VỊ TRÍ CÁC ĐOẠN CODE THƯỜNG GẶP TRONG WORDPRESS + FLATSOME
================================================================================
Khi cần tìm code, nắm được cấu trúc thư mục sẽ giúp bạn định vị nhanh hơn 90%:

1. THƯ MỤC THEME CON (FLATSOME CHILD - NƠI CHỨA CODE TỰ VIẾT):
   Đường dẫn: `wp-content/themes/flatsome-child/`
   - `functions.php`: Nơi chứa toàn bộ custom code PHP, hàm shortcode, hook tùy biến.
   - `style.css`: Nơi chứa CSS tùy biến riêng cho dự án.
   - `woocommerce/`: Chứa các file giao diện ghi đè (override) của WooCommerce.

2. THƯ MỤC THEME GỐC (FLATSOME GỐC):
   Đường dẫn: `wp-content/themes/flatsome/`
   - `inc/shortcodes/`: Chứa toàn bộ mã nguồn của các shortcode Flatsome (`ux_products.php`, `ux_banner.php`, `row.php`, `section.php`...).
   - `inc/builder/`: Chứa cấu hình các element trong UX Builder.
   - `inc/woocommerce/`: Toàn bộ logic tùy biến WooCommerce của Flatsome.
   - `template-parts/`: Các khối Header, Footer, Posts...

3. THƯ MỤC WOOCOMMERCE:
   Đường dẫn: `wp-content/plugins/woocommerce/`
   - `templates/`: Toàn bộ giao diện gốc của WooCommerce:
     + `single-product/`: Giao diện trang chi tiết sản phẩm (ảnh, giá, nút mua, mô tả).
     + `cart/`: Giao diện giỏ hàng.
     + `checkout/`: Giao diện trang thanh toán và trang cảm ơn (order-received).
     + `loop/`: Giao diện từng thẻ sản phẩm trong danh sách.
   - `includes/`: Chứa các hàm xử lý logic, tính thuế, vận chuyển, đơn hàng.

4. THƯ MỤC CƠ SỞ DỮ LIỆU / UPLOAD:
   Đường dẫn: `wp-content/uploads/`
   - Chứa hình ảnh xe đạp, media, file đính kèm tải lên.

IV. CÁCH BẠN TỰ TÌM NHANH TRÊN VS CODE / TRÌNH SOẠN THẢO MÃ NGUỒN
================================================================================
Nếu bạn muốn tự tay tìm kiếm trên máy tính:

1. PHÍM TẮT THẦN THÁNH: `Ctrl + Shift + F` (Windows)
   - Mở thanh tìm kiếm toàn bộ dự án (Global Search) ở cột bên trái VS Code.
   - Gõ từ khóa muốn tìm (ví dụ: `gobike_category_block`).

2. MẸO THU HẸP PHẠM VI TÌM KIẾM (FILES TO INCLUDE):
   - Chỉ tìm trong file PHP: Điền `*.php` vào ô "files to include".
   - Chỉ tìm trong file CSS: Điền `*.css`.
   - Chỉ tìm trong theme Flatsome: Điền `wp-content/themes/flatsome/**`.
   - Bỏ qua thư mục rác (files to exclude): Điền `node_modules, wp-content/uploads`.

3. TÌM NHANH TÊN FILE BẤT KỲ: `Ctrl + P`
   - Gõ tên file cần mở, ví dụ: `functions.php`, `header.php`, `single-product.php` là file sẽ mở ra ngay lập tức.
